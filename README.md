# Discord Server Starter Pack

Welcome! This pack contains resources and inspiration to help bring your Discord server's identity and style to life.

### What's Included

**1. Namebook.txt**
A collection of server name ideas to inspire your next creation.

**2. Discord Server Making Pack – Characters.pdf**
A collection of Unicode characters, symbols, and decorative text elements for customizing channel names and server text.

**3. Logo Ideas/**
A folder of logo inspiration to help shape your server's visual identity.

**4. Server Profile Example.png**
A visual example to inspire your own server profile design.

### How to Use

1. Browse the Namebook and find a name you like.
2. Explore the characters PDF and copy symbols you want to use.
3. Check the Logo Ideas folder for inspiration.
4. Use the profile example as a reference for your own design.

### Tips

- Mix and match ideas to create something original.
- Keep your server name easy to recognize.
- Use symbols sparingly so channel names stay readable.
- Make your colors, logo, and server name feel consistent.

### Have Fun!

Make something that feels uniquely yours!
